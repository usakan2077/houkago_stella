## 画像

 - [x] **立ち絵不足** → 対応済み
   - 延原：体育の授業中でも制服・かばん持ち。
     - → 登場シーンでは基本かばん持ち。あってないシーンが大半なため要修正
   - **→ 対応**：体操服 `nobuhara_sports`（PE用）と、制服かばん無し `nobuhara_nobag`（校内用）を新規追加し `config.js` に登録。
     かばん有り `nobuhara` は通学・校門シーン（ch1朝/ch5下校）専用に限定。
     これで「体育で制服」「屋内で常にかばん」を解消。

 - [x] **立ち絵のサイズバランス不揃い** → 対応済み
   - サブキャラとメインヒロインで立ち絵の大きさが不揃いで、サブキャラが浮いて見える、という報告。
   - 原因：全立ち絵が同一キャンバス（832×1272）でも、PNG内のキャラ描画スケール（バストアップ/全身など枠内の大きさ）がキャラごとに違うため、同じスロットに `contain` 配置すると頭の大きさ等がばらつく。
   - **→ 対応**：キャラ単位の表示倍率 `scale` と接地オフセット `offsetY` を `config.js` に追加（＝奥行きの概念）。
     `game.js` の `_showChar` / `_changeExpr` でスプライトに `transform: translateY(offsetY) scale(scale)`（下端中央を軸）を適用。
     さくら・ことは等を基準（×1.00）に、まひる・サブキャラを個別調整（例：延原系×1.21、shin_child×1.30 など）。既定値（×1.00/0）は無影響。
   - 調整ツール：`assets-src/sprite_test.html`（倍率・接地を視覚比較し config 用JSONを出力）。※開発用のため master には含めない（`assets-src` 配下）。
