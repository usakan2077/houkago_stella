## システム・UI

- [x] **進行状況の初期化機能**（設定モーダル／確認モーダル必須）。セーブ全スロット＋ギャラリー解放を削除、設定は保持。 → 対応済み
  - → 全ルート制覇後、タイトルバック画像が変化してる状態で初期化実行→ 再読み込みするか、ゲーム開始→タイトルに戻ってくるまで変化画像のまま。
    - → 初期化実行と同時にタイトルバック画像も変更できるか？
  - **→ 対応**：`_resetProgress` のリロード依存を廃止。初期化時に `all-good-ends-cleared` クラスを即トグルして**タイトル背景をその場で通常状態へ戻す**。CONTINUEは空スロット表示、ギャラリーは開く度に再構築されるためリロード不要。

- [x] **タイトルに CONFIG ボタン追加**、言語切替を右下隅のコンパクトトグルへ移設、タイトルメニューを整理。 → 確認済み・現状維持
  - → CONFIG内にも同設定は残ってるが問題ないか？
  - **→ 対応**：問題なし。タイトル隅のトグル（素早い切替）と CONFIG 内の言語項目（設定の常設場所）は同じ `data-language` で連動し常に同期。CONFIGを開かないと変えられないと不便なため、両方残す方針でOK。

    - **→ 対応**：開幕背景を **校門 `school_gate_summer_evening`** に変更。「結局、職員室まで付き合って備品を返し、もう一度二人で校門を出た。」の一文を追加し、別れ際で `commute_road_summer_evening`（交差点）へ切替。背景と備品処理の筋を整合。

    - **発見した違和感（まひるルート `mahiru_ch10_run`）**：主人公が走れない理由は全編で「足首の怪我（治っても踏み込めない恐怖）」で一貫（Ch1・Ch2・Ch4）。しかし父の回想だけ「**病院まで走れていた**のに**走れなくなったのはあの夜から**（＝父が倒れた夜）」と原因を別物にしており、足首説と矛盾。さらに同ルートの bad_end は「折れた音・走れなくなった夜」と足首を原因にしておりルート内でも食い違い。
    - **→ 対応**：`route_mahiru.mahiru_ch10_run.t024` を「（走れなくなったのはあの夜から）」→「（あの「大丈夫」を、俺は最後まで拾えなかった）」に差し替え（EN も同期）。父の回想を「大丈夫」を拾えなかったテーマ（直後の慎の件＝同じく気づけなかった、へ接続）に収束させ、足首＝走れない理由の主軸との矛盾を解消。
    - 補足（軽微・対応不要）：背景流用に伴う scene 名と中身の軽いズレ（`sakura_ch9_hospital`=`commute_road_autumn`／ことはエピローグ=`street_plaza_summer`）、Ch3 で5月に文化祭準備の話が出るのがやや早い（伝聞ベースで許容）。

- [x] **延原 成長アーク N1〜N5**（Ch8「だから行け」を地続きにする）
