# LPの比較用バリエーション

| URL | 訴求 | 計測値 `lp_variant` |
| --- | --- | --- |
| `/lp/` | 物語・キャラクターから入る既存版 | `story` |
| `/lp/ai/` | 一人の制作者がスキマ時間にAIとつくった作品、という制作背景から入る別パターン | `ai_solo` |

本編と同じローカルサーバーで比較できます。例：`http://localhost:8080/lp/` と `http://localhost:8080/lp/ai/`。どちらも日本語・英語を切り替えられ、同じ本編へ進みます。OP動画・画像は既存素材を参照し、複製しません。

AI制作版は「たった一人。スキマ時間。AIと、ここまで。」を入口に、制作の過程、完成OP、三人の物語、無料プレイの順で紹介します。制作時間・費用は未掲載。確認済みの制作表記として、シナリオ改稿・オープニングMVはChatGpt-6、ボイス制作はElevenLabsを掲載しています。全素材がAI生成であるとは表現していません。

## 比較の方法

別URLとして用意しており、自動振り分けはしません。同じ時期・似た流入元でそれぞれのURLを案内して反応を見るための下地です。別々のSNS投稿の数字だけでは、投稿内容や流入ユーザーの違いも影響します。

既存のGA4タグに、共有スクリプト `experiment.js` から次のイベントを送ります。

| イベント | タイミング | 主なパラメーター |
| --- | --- | --- |
| `lp_view` | ページ初期表示 | `lp_variant`, `language` |
| `lp_play_click` | 本編へのリンクをクリック | 上記＋`cta_position`（`hero` / `footer` / `other`） |
| `lp_op_play` | AI制作版のOPが実際に再生を開始（ページ内で初回のみ） | `lp_variant`, `language` |

比較するのは、各版の閲覧に対して本編リンクを押した割合です。`lp_play_click` は本編の起動成功やプレイ完了を意味しません。広告ブロッカーなどで計測されない訪問もあります。GA4側のレポート設定・集計・自動振り分けは別作業です。

## 更新時の注意

AI制作版のテキストは `ai/index.html` の日本語と `data-en` の英語を合わせて編集します。既存版の更新履歴へリンクする構成なので、リリース履歴を二重管理しません。

## 動作確認

Windows・Edge・Python の環境で `python tools/check_lp_variants.py` を実行すると、新旧LPの日英切り替え、スマホ幅、プレイリンクの計測と、新版の画像表示・OP再生を確認します。外部通信をブロックし、計測はローカルの `dataLayer` への記録まで検証します。既存版の画像読み込み失敗は、今回の変更箇所と分けてレポートに記録します。

2026-10-13：共通の更新履歴に日英全編ボイス、ことはLeira版、ログ再生・音量・再生表示、シナリオと演出の見直し、クレジットの追加を掲載。両LPの紹介文も日英ボイス対応に合わせ、既存版のことはの旧名を花園ことはへ統一しました。

## フルボイスを入口にした紹介（2026-10-13）

既存版は作品タイトルを最大の見出しとし、その下で日英フルボイスを特徴として掲示。物語・ヒロイン紹介・無料プレイへ進む構成へ変更。試聴は独立セクションを設けず、3人のヒロイン紹介カードに配置。AI制作版でも、3人の紹介カード内に同じ試聴を配置しています。更新履歴だけでなく、声を作品の魅力として紹介します。

voice-preview.css／voice-preview.jsが両LP共通の試聴表示・操作です。srcとgainは本編の採用manifestから選んだ値をHTMLへ保存。今後テイクを差し替えたら両LPのdata-ja-src／data-en-src／gainも合わせます。音声はクリック時だけ取得し、言語変更・タブ非表示・ページ遷移・OP再生で停止。既存音声を使うので生成APIは呼びません。

検査は tools/check_lp_variants.py に日英の実音声試聴・停止・言語切替時停止・初期音声未取得を追加。PCと390px／320pxで両LPを確認済み。試聴用WebPは元PNGとRGBAピクセルが完全一致する可逆変換で、構図はCSSで調整しています。

通常LPにも冒頭の次にOPムービー再生セクションを追加。既存assets/video/stella-op.mp4を参照し、controls／playsinline／preload=noneで手動再生。試聴とOPは互いに再生を停止し、音が重ならないようにしています。

2026-10-20：ver 1.3.1の更新履歴を日英で統一。ボイス修正・音量、場面のつながり、まひるの屋上への走行、全7ENDとタイトルの改善を掲載。両LPの試聴音声は現行manifestの章別パス・補正音量へ更新。
