# LPの比較用バリエーション

| URL | 訴求 | 計測値 `lp_variant` |
| --- | --- | --- |
| `/lp/` | 物語・キャラクターから入る既存版 | `story` |
| `/lp/ai/` | 一人の制作者がスキマ時間にAIとつくった作品、という制作背景から入る別パターン | `ai_solo` |

本編と同じローカルサーバーで比較できます。例：`http://localhost:8080/lp/` と `http://localhost:8080/lp/ai/`。どちらも日本語・英語を切り替えられ、同じ本編へ進みます。OP動画・画像は既存素材を参照し、複製しません。

AI制作版は「たった一人。スキマ時間。AIと、ここまで。」を入口に、制作の過程、完成OP、三人の物語、無料プレイの順で紹介します。制作時間・費用・使用したAIの具体的なサービス名は未確認なので掲載していません。全素材がAI生成であるとは表現していません。

## 比較の方法

別URLとして用意しており、自動振り分けはしません。同じ時期・似た流入元でそれぞれのURLを案内して反応を見るための下地です。別々のSNS投稿の数字だけでは、投稿内容や流入ユーザーの違いも影響します。

既存のGA4タグに、共有スクリプト `experiment.js` から次のイベントを送ります。

| イベント | タイミング | 主なパラメーター |
| --- | --- | --- |
| `lp_view` | ページ初期表示 | `lp_variant`, `language` |
| `lp_play_click` | 本編へのリンクをクリック | 上記＋`cta_position`（`hero` / `footer` / `other`） |
| `lp_op_play` | AI制作版のOPが実際に再生を開始（ページ内で初回のみ） | `lp_variant`, `language` |

比較するのは、各版の閲覧に対して本編リンクを押した割合です。`lp_play_click` は本編の起動成功やプレイ完了を意味しません。広告ブロッカーなどで計測されない訪問もあります。GA4側のレポート設定・集計・自動振り分けは別作業です。

## 更新時の注意

AI制作版のテキストは `ai/index.html` の日本語と `data-en` の英語を合わせて編集します。既存版の更新履歴へリンクする構成なので、リリース履歴を二重管理しません。

## 動作確認

Windows・Edge・Python の環境で `python tools/check_lp_variants.py` を実行すると、新旧LPの日英切り替え、スマホ幅、プレイリンクの計測と、新版の画像表示・OP再生を確認します。外部通信をブロックし、計測はローカルの `dataLayer` への記録まで検証します。既存版の画像読み込み失敗は、今回の変更箇所と分けてレポートに記録します。
