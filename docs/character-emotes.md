# 立ち絵エモート（2026-10-12）

[動く実装見本](../dev-preview/emote-preview.html) をブラウザで開く。見本HTMLはローカル確認用としてGit管理外に置く。普段のローカルサーバーなら `/dev-preview/emote-preview.html`。既存の立ち絵と背景を使用し、さくら・ことは・まひる・延原、動きの強さ0.35〜1.5、15種類の演出を比較できる。見本の台詞は動きを示すサンプルで、本編を改稿したものではない。

共通実装は `character-emotes.js` と `character-emotes.css`。見本と本編が同じ実装を使う。表示済み画像の親 `.char-sprite` を動かし、画像の既存倍率・接地位置・スロットの中央寄せ・入退場のアニメーションは別の階層に残す。Web Animations APIで実行し、音声API・追加画像生成・外部ライブラリは使わない。

## 本編の呼び出し

```text
@expr sakura happy
@emote sakura joy 0.7
sakura: $既存の台詞ID

@expr kotoha sad
@emote kotoha slump 0.6
kotoha: $既存の台詞ID
@emote kotoha clear
```

構文は `@emote 対象 名前 [強さ]`。強さの省略時は1.0。今回の本編では0.35〜0.5程度の控えめな強さを使う。対象は立ち絵名、役の基本名、left／center／right／allを使える。たとえば表示中が `sakura_sports` でも `@emote sakura shy 0.6` で同じ役へ届く。複数の位置に同じ役があればすべて対象になるので、一人だけを指定したいときは位置名を使う。

表情を先に切り替え、その後でエモートを付ける。`@emote`自体は顔の表情や音声を変えず、読み進めを待たせない。特に`slump`・`fall`は姿勢を保持するため、次の会話で `clear` を入れる。すべて戻す場合は `@emote all clear`。同じ人物の次のエモートは前の動きと装飾を取り消して置き換える。

退場・移動・表情が変わる画像の差替え・背景変更・スチル表示・スキップ開始で解除する。同じ表情の `@expr` は画像を差し替えないため、姿勢を戻す目的には `clear` を使う。スキップ中は新しいエモートを開始しない。初回画像が読み込まれる前の命令は現在の表示要求へ預け、退場・差替え・スキップで取り消す。ロード後に途中の動きを再開する目的では保存しない。

OSの「動きを減らす」が有効なら立ち絵の移動・揺れと粒子の移動を止め、星などの装飾は静止して短時間だけ表示する。

## 台詞への適用方針

本編の日英へ41箇所の動きと4箇所の明示的な解除を追加した。[適用箇所と付けずに残した場面](scenario-review/emote-implementation-2026-10-12.md) に判断を記録している。強さは0.35〜0.5。全台詞を機械的に動かす方針にはしない。

- 嬉しい台詞でも、軽口なら `bounce`、控えめな喜びなら `sparkle` の弱めを選ぶ。
- まひるの孤立、重い告白、父親の急変などは、装飾の印が場面を軽くしないかを優先する。震えを使う場合も弱く短く。
- 聞いている人物には `nod` や、短い `startle` を必要なところだけ付ける。
- `shy` は照れ顔と短い間を合わせる。`slump` の解除やスチルから戻る姿勢も、台詞の前後で決める。

## 粒子の調整（2026-10-12・ユーザー試見後）

キラキラは7個から3個、12〜17pxの小さな光に抑えた。ハートは4個から2個、14〜16pxへ縮小。両方とも発光を抑え、ピークの不透明度をそれぞれ0.55／0.45、浮き上がる距離を10px程度にして、表情へ控えめに添える。`joy`にも同じキラキラの調整が反映される。

「あせあせ」は顔の横からしずく3つが、上・横・下の方向へ扇状に飛び散る動きへ変更。丸みと尖った先端のある形にし、淡い縁取りで背景から見分けやすくした。動きを減らす設定では3つを静止表示する。

装飾の位置は、スロットの空白ではなく実際に表示した立ち絵画像の領域を基準にする。画像の縦横比や倍率が違っても、汗や光が頭から遠く離れないようにした。


## 怒りの調整（2026-10-12・ユーザー試見後）

`anger`の「＋」に見える文字を、四つの曲線で作る青筋のSVGへ変更した。18pxの灰青色で発光させず、頭の近くで0.78〜1.1倍程度の拡大縮小だけを行う。上へ浮かせない。青筋はコミカルに見えやすいため、仲間への軽い文句などに限定して検討する。

記号を出さない `irritated` も追加。通常の怒りや傷ついた拒否にはこちらと表情・声の演技を合わせる案を基準にし、見本で青筋ありと比較できるようにした。本編では青筋を使わず、日常の数合わせへの不満1箇所に `irritated 0.35` を使う。


## 震えの調整（2026-10-12・ユーザー試見後）

`@emote 人物 tremble 0.35` を基準とし、震えは最小値0.35を上限にした。省略時や大きな値を指定しても、実行側でこの上限を守る。左右の変位は最大0.7px、回転はなし。揺れる・よろける表現へ広げず、かすかな震えに留める。

見本では「かすかに震える」を選ぶと、強さを0.35に固定する。他の演出へ戻ると元の強さを復元する。本編に使うときも弱く短く、必要な場面に限る。
