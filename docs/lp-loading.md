# LPの初回表示を妨げる読み込みの改善

2026-11-18、1.4.8のLPに対する修正。ゲーム本文・音声・映像は変更しない。

言語対応で追加した3本のスクリプトがhead内でHTMLの解析を止めていた。初期表示に必要な本文より先に全言語の辞書取得を待つ構成だった。また、日本語のヒーロー画像は約2MBのPNGで、通常LPの下部画像とX埋め込みも初期読み込みに重なっていた。

## 変更

- 両LPのローカルスクリプトを順序を保つ `defer` に変更。辞書の通信が遅れてもHTML・画像・本文を先に表示する。静的な各言語ページは最初から対象言語の本文を持つ。
- 日本語ポスターをPillowで表示サイズに合わせてWebPへ書き出し、2,038,394から207,428 bytesへ削減。全5言語のヘッダーロゴも小さい表示用に出力し、元の約169～510KBから約26～37KBへ削減。ゲームの大きなロゴや原画像は維持。
- 画面下の画像に `loading=lazy`、ヒーロー画像に優先度指定を追加。Xウィジェットは掲載欄の400px手前まで近づいたときだけ取得する。通常のXリンクは維持。
- OPの選択済みURLを絶対URLで比較し、同じ動画への不要な `load()` を防ぐ。OPの手動再生・字幕・計測・言語切替は維持。
- LPのキャッシュ識別子は `1.4.8-lp2`。通常・AI制作版の英語／簡体字／繁体字／韓国語の静的8ページも再生成する。

画像の再生成は `py tools/optimize_lp_images.py`、出力のサイズ・元ファイル・ハッシュは [lp-image-exports.json](lp-image-exports.json)。続いて `py tools/build_chinese_landing_pages.py` で静的LPを更新する。

## 計測

隔離Edge、390px、初回キャッシュなし、ローカルHTTPサーバーで3Mbps・遅延150msを再現。外部計測を遮断した1回ずつの比較で、実ユーザーの通信速度や分布を示すものではない。取得量はdocument load終了付近までのResource TimingのencodedBodySize合計で、外部広告・計測は含まない。

| ページ・言語 | 初期取得量：修正前→後 | 最初の本文描画（FCP）：修正前→後 |
| --- | ---: | ---: |
| 通常LP・日本語 | 6.44MB → 1.02MB | 2.41秒 → 1.69秒 |
| 通常LP・韓国語 | 4.74MB → 1.02MB | 2.50秒 → 0.96秒 |
| AI制作版・日本語 | 2.69MB → 0.86MB | 2.53秒 → 0.86秒 |
| AI制作版・韓国語 | 0.87MB → 0.87MB | 2.40秒 → 0.70秒 |

単一計測の時間は回線・ブラウザー実行の揺れを含む。JSON証跡はリポジトリ外の `lp-performance-20261118/before.json` / `after.json`。本番公開後も別途確認する。

- `py tools/check_lp_loading.py`：言語辞書の応答を止めても日本語・韓国語の両LPが描画されること、国判定前のキャンペーン非表示、初期表示時の音声・動画データやX埋め込みの取得抑制、下部画像の遅延、スクロール後のXローダー起動を確認。
- `py tools/check_korean_browser.py`：5言語往復・韓国語音声・OP・字幕・スマホ幅・セーブ復元。
- `py tools/check_multilingual_media.py`：英語・中国語のLPとOP・字幕の回帰。
- `py tools/check_bonus_scenario.py --campaign-country-only`：日本語・日本アクセスだけにキャンペーンを表示する制限の回帰。
