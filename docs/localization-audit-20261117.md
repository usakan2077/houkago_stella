# 英語・中国語対応の棚卸し — 2026-11-17

対象は日本語・英語・簡体字・繁体字の公式サイト、ゲーム本編・おまけ。本文翻訳、録音、画像、動画、配布物を分け、未確認のものを対応済みと扱わない。

| 対象 | 英語版の確認結果・対応 | 簡体字・繁体字の確認結果・対応 |
|---|---|---|
| 本編・おまけ本文／操作画面 | 既存対応。全本文参照・分岐・音声IDを再検査 | 翻訳済み。全本文参照・分岐・音声IDを検査 |
| 会話音声 | 各1,196台詞。既存ファイルを維持 | 各1,196台詞を登録。抜き取り音声認識17件のうち9件は要試聴 |
| ゲームのタイトルロゴ | 既存の英語ロゴを使用 | 専用の透明ロゴを追加済み |
| OP映像内の名前・台詞・ノート・タイトル | 既存の英語OPは対応済み | 編集データから専用1080p映像を制作。全フレーム・元音源・共通区間を照合済み |
| OPの歌詞字幕 | 英訳16区間を追加 | 両表記16区間を追加。日本語表示では日本語字幕を任意でオンにできる |
| LPロゴ・ポスター・共有画像・キャンペーン画像 | 日本語画像が残っていたため英語へ差替 | 両表記の画像へ差替済み |
| キャンペーンの案内・応募用投稿文 | 日本語以外では非表示。日本語選択時もアクセス元の国が日本と確認できた場合だけ表示。居住条件は維持 | 日本からのアクセスでも非表示。通常のクリア記録・感想共有を残す |
| LPの画像説明・読み上げラベル | 日本語が残っていたため翻訳。試聴ボタンのラベルが日本語へ戻る問題も修正 | 試聴ボタンの名前・操作ラベルを言語に合わせて維持 |
| 共有・検索用の静的LP | `lp/index.en.html` / `lp/ai/index.en.html` を追加 | 両表記×2種類のLPを追加済み |
| ホーム画面追加時の表示 | 日本語のmanifestを使っていたため英語版を追加 | 両表記のmanifestを追加。LPとゲームの言語を引き継ぐ |
| ED歌詞・クレジット | 既存対応。歌詞17・15・15区間と英訳・ローマ字の対応を確認 | 表示文言は翻訳済み |
| 導入・おまけの共通動画 | 文字のない映像部分は共通素材として維持 | 同左。操作UIは表示言語に対応 |

## 意図して共通のもの

- OP・EDの歌唱は日本語音源。音楽を新たに生成せず、歌詞字幕・訳文で対応する。
- 制服の校章、作者のブランドロゴ、公式Xのユーザー名・応募ハッシュタグ、素材の正式な出典は原表記を維持する。
- 繁体字版の会話音声も普通話。同じ読み・演技・文脈は簡体字版と音声を共有する。

## 制作・検証記録

- 英語追加画像：[english-promo-assets.json](english-promo-assets.json)。元素材は素材リポジトリーの `assets-src/multilingual-release-20261117/`。
- 中国語OP：[chinese-op-production.json](chinese-op-production.json)。既存の編集プログラム・採用画像・タイミングを再利用し、元AACをコピーする。未変更の日本語・英語MP4は上書きしない。
- OP字幕：[op-subtitle-source.json](op-subtitle-source.json)。元SRTの16区間を維持。映像下部の台詞と重ならないよう上部へ表示する。
- 字幕の再生成は `py tools/build_op_subtitles.py`、原稿との照合は `py tools/build_op_subtitles.py --check`。翻訳サービスや生成APIは呼ばない。
- 音声認識の要確認箇所：[chinese-voice-sample-review.json](chinese-voice-sample-review.json)。認識差だけで誤読と断定しない。
- `tools/check_multilingual_media.py`：LP6ページの静的情報・実画像・試聴・320px／390px表示、4言語OPの映像・音声・16区間字幕・キーボードでの字幕切替とスキップを実Edgeで検査する。
- `tools/build_chinese_landing_pages.py` は従来名を維持しているが、英語・簡体字・繁体字の計6ページを生成する。本文・画像・字幕・metadata変更後は再生成する。
- キャンペーンの地域・言語制限は `py tools/check_bonus_scenario.py --campaign-country-only` で検査する。9つの静的入口の初期非表示、日本から日本語を選択した場合だけ表示、言語切替時の応募ルール・共有・コピーの更新、海外・国判定エラー・タイムアウト時の非表示、通常のクリア記録の維持を確認する。[表示制限の詳細](bonus-clear-campaign.md)。

## 残す確認事項

1. 音声認識で候補になった中国語9件の実聴。本文・人名の読みや演技の誤りが確認できた場合にだけ別テイクを制作する。
2. 母語話者による訳文・音声の通し確認。機械検査は自然さを保証しない。
3. 実機のiPhone／Androidでホーム画面追加後の表示を確認。manifestと起動URLはブラウザで検査するが、OSのインストール結果は別途確認する。
4. 本番公開と外部配布サイト用アーカイブの再作成はリリース時の作業。既存の配布紹介原稿は日英ビルド向けなので、配布ビルドへ含めた言語を確認してから公開文面を更新する。
