# デバッグ報告15 対応記録

対象: 1.3.8 の報告。対応版: 1.3.9（2026-10-23）。

## 章切り替え

章タイトルの後、黒く覆った状態で次章の背景・立ち絵・最初の文章を準備し、通常のダイヤモンド暗転の後半（開く部分、600ms）のみを実行する。次章が先に見えてから閉じる動きは入れない。

背景の準備が非同期になった場合も、準備完了まで黒いカバーを維持する。ゲームのリセットは待機中の背景読み込み・章移動・開くアニメーションを取り消す。EDからエピローグへの移行は、クレジットの下で準備してそのまま表示する従来の動作を維持する。

## サウンドモード

- タイトルメニューにクリア特典として追加。いずれかの最終エンディング到達（GOOD/BAD両方）で `vn_sound_unlocked` を永続保存する。章の終了では解放しない。
- 既存のGOOD END記録、または旧版のエピローグCG解放記録があれば、再クリアせず利用できる。旧版のBAD END単独クリアには専用の保存記録がないため、新版でエンディング到達が必要。
- OP・ED4曲、BGM32曲を日本語・英語の曲名付きで収録。曲の定義は `config.js` の `soundTracks`、画面・音声管理は `sound-mode.js`。
- 音楽の再生、一時停止、シーク、前後の曲、リピート、音量変更に対応。音量は本編のBGM設定と共有。
- 試聴中はタイトルBGMを停止し、OPの無操作再生も待機する。閉じるボタン・Escape・外側クリック・右クリックで音声を停止してタイトルBGMへ戻る。ゲーム開始・リセットでも試聴を停止する。
- 進行状況の初期化で解放を取り消す。設定・音量は残る。
- OP音源は隣の制作フォルダー `houkago-stella-op/放課後のステラ.mp3` を `assets/audio/bgm/opening_theme.mp3` にコピー。ED・BGMは既存ファイルを参照する。
