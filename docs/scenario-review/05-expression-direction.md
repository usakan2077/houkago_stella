## 使える命令と限界

- @expr：既存の表情差分へ切替。実画像と config.js の登録を確認する。
- @show の fade_in／slide_in_left／slide_in_right／pop_in：登場の演出。
- @hide の fade_out／slide_out_left／slide_out_right：退場の演出。
- @move char left|center|right [slide|instant]：位置変更。現行の slide は連続的な横移動ではなく、元位置で消して約300ms後に新位置へ出す実装。軽い後退や身体の揺れをそのまま表す命令ではない。
- @shake は画面全体への揺れ。人物の小さな身振りに常用しない。
- 腕を振る、座る、ラケットを振り切るなどは、画像のポーズを変える素材が必要。上下への小さな移動・連続的な横移動・個別人物の揺れは、機構を追加する場合の候補。

既存の表情変更はボイスを作り直さず反映できる。台詞の本文や場面の感情が変わる案は、採用後に演技指示と previous_text／next_text を見直す。

## 演出を足すときの順序

1. 場所・衣装・持ち物の整合を直す。
2. 一つの感情の変わり目につき、まず一回の表情変更を試す。
3. 近づく・去るなど距離に意味がある場面だけ移動を使う。
4. 全章へ同じ動きを貼らず、静かに読む時間を残す。
5. ボイス再生中、クリック送り、スキップ、ロード復元で表示が破綻しないか確認する。
