# 第4周：型の反復・説明過多・AIらしく見える表現

現在の判断は末尾の第3回チェックを優先し、修正履歴は各項目の「対応（2026-10-12）」と [修正対応記録](implementation-2026-10-12.md) を参照。以下の原文引用はレビュー時点の本文を残している。
確認期間：2026-10-11〜12。全12ファイルを、説明の型、比喩、会話の均質さ、結末の教訓化を中心に再確認。AIによる作成かどうかを文章から判定するレビューではない。「AI特有」と断定せず、読者に機械的な反復を感じさせる可能性を扱う。

現行稿には、プリントの三分の二、弁当の魚、洗剤の匂い、土足への指摘など、人物と状況に結びついた会話が多い。抽象語や詩的な台詞があるだけで削る必要はない。

## STYLE01｜推敲検討｜主人公が会話直後に自分の誤りを説明する形が重なる

**対応（2026-10-12）：採用・実装済。** ことはの話を奪った自己分析を質問を飲み込む動作へ。まひるへの返答も即座の自己採点を減らした。

- 対象：`chapter3.chapter3_library_talk.r020.s002`（[chapter3.md:181](../../scenarios/chapter3.md#L181)）
  - レビュー時の本文：俺のほうで勝手に、許す言葉を待っていたらしい。
- 対象：`chapter7.chapter7_monologue.r002.s003`（[chapter7.md:432](../../scenarios/chapter7.md#L432)）
  - レビュー時の本文：考え始めると、どれも格好のいい台詞になって嫌になった。
- 対象：`route_kotoha.kotoha_ch10_start.r027`（[route_kotoha.md:170](../../scenarios/route_kotoha.md#L170)）
  - レビュー時の本文：言われて初めて、続きを奪ったことに気づいた。
- 対象：`route_mahiru.mahiru_good_end.r010`（[route_mahiru.md:446](../../scenarios/route_mahiru.md#L446)）
  - レビュー時の本文：自分でもひどい返しだと思った。

指摘：相手の反応→自分は何を間違えたかの言語化、が共通編と各ルートで繰り返される。主人公の内省として必要だが、毎回本人が正確に分析すると読者の発見を先に説明してしまう。AI作成の証拠ではなく、説明の型の指摘。

案：謝ったあとに許す言葉を待っていた場面は残し、ことはに「わたしの話を聞いて」と言われる場面では、反省の説明を「次の質問を引っ込めた」等の行動へ替える案。まひるの手紙に答えられない箇所は、即座に「ひどい返し」と採点せず、次のまひるの台詞を待ってもよい。

## STYLE02｜推敲検討｜進捗の三十ページが別のヒロインでも重なる

**対応（2026-10-12）：採用・実装済。** さくらは部活の連絡で同じ箇所へ戻る、ことはは読み進めた章で報告する形に分けた。

- 対象：`route_sakura.sakura_ch9_end.r001`（[route_sakura.md:244](../../scenarios/route_sakura.md#L244)）
  - レビュー時の本文：本、明日じゃなくていい？　まだ三十ページ
- 対象：`route_kotoha.kotoha_ch10_decide.r001`（[route_kotoha.md:254](../../scenarios/route_kotoha.md#L254)）
  - レビュー時の本文：三十ページまで読みました
- 対象：`route_kotoha.kotoha_ch12_branch.r004`（[route_kotoha.md:399](../../scenarios/route_kotoha.md#L399)）
  - レビュー時の本文：三十ページ、やっと越えました

指摘：別ルートでヒロインが主人公に借りた本を三十ページまで読んだと報告する形が重なる。数そのものは自然だが、同じ小道具・同じ進捗で距離を示すと、別の二人にも同じ会話の枠を使った印象になる。

案：ことはは曲名を調べて読み直した箇所、さくらは読書中に部活の連絡が来て止まった箇所など、読み方を変える。両方が本を借りる関係は保ってよい。ことはの同じ三十ページの再登場は JP10 も参照。

## STYLE03｜推敲検討｜最終選択肢が物語の正解を説明しすぎる

**対応（2026-10-12）：採用・実装済。** さくらの選択を今週の用事と予定の確認へ寄せた。依存は後の先回りと判断を任せる場面で示す。

- 対象：`route_sakura.sakura_ch12_branch.r002`（[route_sakura.md:507](../../scenarios/route_sakura.md#L507)）
  - レビュー時の本文：さくらの予定を聞いてから、手伝えることを決める
- 対象：`route_sakura.sakura_ch12_branch.r003`（[route_sakura.md:508](../../scenarios/route_sakura.md#L508)）
  - レビュー時の本文：これからは、できるだけ俺が引き受ける

指摘：「予定を聞いてから、手伝えることを決める」と「できるだけ俺が引き受ける」は、支援と依存というルートの主題をそのまま要約する。選ぶ前に作者の採点基準が見え、場面の中の判断より教訓の確認になりやすい。

案：今週の予定を聞く／今日は俺が全部運ぶ、のように目の前の用事へ寄せる。ただし、後者一回の手伝いだけで依存結末になるのは飛躍なので、反復される態度を後続場面で見せる。選択肢だけ短くして結果の理由を失わないこと。

## STYLE04｜構成検討｜二つの父親の病気が同じ「倒れる」形で物語を動かす

**対応（2026-10-12）：見送り・主題を維持。** 父の病気を別事件へ置き換える案は採らない。さくらの日常の負担、ことはの演奏時の記憶という異なる焦点を維持する。

- 対象：`chapter8.chapter8_sakura_crisis.r008`（[chapter8.md:186](../../scenarios/chapter8.md#L186)）
  - レビュー時の本文：お父さんが倒れたって。家の近くで。救急車で運ばれたって
- 対象：`route_kotoha.kotoha_ch10_start.r007`（[route_kotoha.md:146](../../scenarios/route_kotoha.md#L146)）
  - レビュー時の本文：十四歳のとき、全国ジュニアの本選で。弾いている途中に、父が倒れました

指摘：さくらの父とことはの父が、倒れて救急対応により助かる、という形でヒロインの課題を動かす。主人公の父の死とも響き合う一方、危機を揃えるための仕掛けにも見え得る。作品の意図的な対照なら残してよい。

案：病名を変えて差をつけるより、さくらは入院後の日常・家事・母への連絡、ことはは演奏中の判断と音への反応を軸にし、語りの焦点を分ける。倒れた説明を各ルートで何度も再要約しない。

## STYLE05｜推敲検討｜後悔の締めを各章で同じ段取りにしない

**対応（2026-10-12）：採用・実装済。** 第3章は短い連絡を送る小さな変化へ。共通Bad Endは連絡を送れない結末を残す。

- 対象：`chapter3.chapter3_end.r004`（[chapter3.md:305](../../scenarios/chapter3.md#L305)）
  - レビュー時の本文：さくらに課題のことしか言わなかった。
- 対象：`chapter7.chapter7_monologue.r002`（[chapter7.md:430](../../scenarios/chapter7.md#L430)）
  - レビュー時の本文：扉に指をかけていたところへ、陸上の話をした。
- 対象：`bad_end.bad_end_monologue.r002`（[bad_end.md:131](../../scenarios/bad_end.md#L131)）
  - レビュー時の本文：さくらに病院の名前を聞く文を打った。
- 対象：`bad_end.bad_end_monologue.r003`（[bad_end.md:133](../../scenarios/bad_end.md#L133)）
  - レビュー時の本文：消した。

指摘：言えばよかった→言う内容を考える→言わない／消す、の流れが章末とBad Endで重なる。主人公の問題として一貫しているが、全場面が同じ意味へ着地すると、日常会話が主題の例題に見えてくる。

案：章末すべてに説明を足すのでなく、未返却の物、次に会う約束、送った短文など、結果が少し変わる場面を残す。共通Bad Endの送れないメッセージは結末として効くので、むしろ通常章側の似た締めを間引く。

## 残したい表現と、数による確認

- 第3章の「休みが短かった」という読書記録の間違いは、さくらの聞き漏らしと主人公の未完成の課題が絡む。人物ごとの事情があり、自然な笑いになっている。
- 第4章の「明日の空気の匂い」→コインランドリーの洗剤は、まひるの比喩を主人公が具体物へ戻す。詩的な一言を一律に削るより、この掛け合いを残したい。
- ことはルートの「下手ですね」→「今、お前が押したんだろ」は、二人の接触の照れとピアノの動作が同時に出る。説明文を増やさないほうがよい。
- まひるのプリン、数学のノート、土足、写真の渡し忘れは、重い話の合間に生活が続いている感じを作る。悲しい場面だからという理由で消さない。
- 全日本語辞書を検索すると「持ち直」は3件、「言いかけ」は4件、「口を開」は4件。これらの語が大量に乱用されている、という指摘は採用しなかった。頻度と局所的な役割を分けて評価する。
- 第1・2・5・6章には、独立した定型表現の修正必須項目をこの周では追加しなかった。三人の口調を同じ丁寧な説明口調へ揃える変更も不要。

## 第2回チェック（2026-10-12）

全12ファイルを、説明の重複、主題の言い直し、会話の型、人物ごとの語り方で再確認した。STYLE01〜STYLE05は未修正。新しい独立した定型表現の修正必須項目は追加していない。

- 「言えない」「送らない」の反復は主人公の課題でもある。全削除せず、通常章では少し行動できる場面も残し、Bad Endで反復が意味を持つようにする。章ごとの情報量は [第8観点](08-pace-foreshadowing.md) に記載。
- ことはの「同じではありません」「今は、わたしの話を聞いてほしかったです」は、整った文でも性格と場面に合う。AIらしいという理由で砕けた口調に変えない。
- さくらの「返信しなくていい」と書けば傷つかずに済んだかもしれない、という遠回りな発言は、取り乱している本人の防御として成立する。説明文を足して意味を全部解説するより、音声の区切りを確認する。
- 三人が泣くこと、走ることが解決へ関わることは作品の共通主題としても成立する。型の反復の評価を [ROUTE01・ROUTE02](10-route-distinction.md) に具体化した。すべて別の事件へ置き換える案ではない。
- 言い回しからAIによる執筆かどうかは判定していない。読者への効果と人物への適合を判断の根拠にする。
