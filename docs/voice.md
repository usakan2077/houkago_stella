# 台詞ボイス

制作・配役・改稿時の音声更新は[ボイス制作仕様](../../houkago-stella-voice/ボイス制作仕様.md)を正とする。2026-10-13、全編日本語1,040台詞・英語1,040台詞、全12役を登録済み。新規各1,006件、承認済み冒頭各34件を再利用。改稿延原r009と、まひるルートの画面外先生teacher_safetyも収録済み。[制作記録](../../houkago-stella-voice/samples/full-v2/README.md)を参照。

主人公・地の文・内心・選択肢・通信の引用は無音。全分岐・回想・衣装違いの話者付き台詞を収録する。本文変更は音声を自動失効させないため、合わなくなったIDはmanifestから外す。音声は制作済みファイルを配信し、ゲーム内で生成APIは呼ばない。APIキーはゲームへ置かない。

## 現在の動作

- 起動時は選択言語の小さな `manifest.json` だけを取得する。音声本体は一括ロードしない。
- 台詞を表示すると現在の音声と先の3台詞を取得する。地の文・主人公は除く。ジャンプ・条件分岐・選択肢・章末などの手前で止め、移動後に取得し直す。未選択ルートは先読みしない。
- スキップ開始時に再生を止め、未完了の音声取得を中断する。スキップ中は新たな取得・再生を行わない。すでに転送済みのデータは取り消せない。
- 既読のみスキップが未読で止まったときは、その台詞から通常の再生に戻る。手動でスキップを解除した場合は次の台詞から再生する。
- 手動で次の台詞へ進むと前の音声を止める。文字送り途中のクリックで全文表示しただけなら音声は続く。
- オートは従来の読書待ち時間と、その台詞の音声終了の両方を待つ。取得失敗・未収録・ミュートでは通常の文字送りに戻る。
- ログは従来どおり直近40件。音声一覧に登録された台詞だけ再生ボタンを表示する。再生中に同じボタンで停止、別のボタンで切り替え。閉じたときも停止する。
- ログのボイス操作はスピーカーアイコンで表示し、再生中は停止マークへ切り替える。ツールチップ・読み上げラベルで操作内容を確認できる。
- メッセージの名前横には、収録済みの台詞でスピーカーと5本のバーを表示する。再生中だけメーター風に動き、終了後は静止、ミュート中は薄く表示する。実際の音圧を示すメーターではなく、再生状態を示すアニメーション。未収録・主人公・地の文では非表示。OSの「動きを減らす」設定時は静止表示にする。
- ログ・セーブ/ロード・CONFIGを開くとオートとスキップを解除する。閉じても自動再開しない。ログ内の再生で本編を進めない。CONFIGでは現在の声を流したまま音量を調整できる。
- タイトル・ロード・言語変更で再生と古い取得を破棄する。非表示タブでは再生・先読みとオート/スキップを止める。
- ボイス音量はBGM・SEと独立した0〜100%。`vn_voice_volume` に保存し、0なら音声取得も止める。ミュート解除後は次の台詞またはログから再生する。
- 表示言語に対応する音声だけを使う。英語音声が未収録でも日本語音声へ自動で置き換えない。

## 音声の登録

台詞の `$chapter1.start.r002` などのIDをキーにする。シナリオの行番号や翻訳後の文章はキーにしない。衣装違いでも台詞IDの仕組みは同じ。

地の文は引用・括弧の外側にある文末で一文ずつの行に分割し、続きに `.s002` 以降のIDを使う。台詞本文・台詞IDと既存音声は維持しているため、この分割だけを理由に音声を生成し直す必要はない。本文や演技・前後文脈を改稿した台詞は、収録前に改めて確認する。

日本語は `assets/voice/ja/manifest.json`、英語は `assets/voice/en/manifest.json`。例（形式説明用）:

```json
{
  "language": "ja",
  "clips": {
    "chapter1.example.r001": {
      "src": "assets/voice/ja/chapter1.example.r001.mp3"
    }
  }
}
```

`src` はゲームの `index.html` を基準としたURL。MP3等、ブラウザがデコードできる形式を使用する。実際に配置済みの音声だけを登録すれば、未制作分への404アクセスを避けられる。IDと台詞内容を照合してから登録する。地の文と主人公は登録しても本編・ログから再生しない。

セーブ形式は変更していない。既存セーブをロードすると、復元された台詞のIDで音声を再生する。音声データや再生途中の秒数をセーブへ格納しない。ログ自体の保存範囲も従来のまま。

## 読み込み・音量補正

`config.js` の `voice` で先読み数・キャッシュ数・容量・取得待ち上限を変更できる。初期値は先3台詞、最大12件／デコード後32 MiB、取得待ち8秒。大きすぎる音声は再生対象から外す。Web AudioのGainNodeで音量を制御する。利用不可・自動再生制限・壊れた音声があってもテキストを読める。

音量補正は音声の制作時に測定して決める。必要なら一覧の各音声に `"gainDb": 2` のような再生ゲインも設定できる（-12〜+12 dB、未指定0 dB）。自動ノーマライズや音割れ防止リミッターではないので、補正済み音声へ二重に加算しない。

2026-10-13の全編版は、承認済み冒頭各34件のファイル・ゲインを維持した。新規録音はその役・言語の補正後有声音RMSを目標とし、個別のサンプルピークが-1 dBFSを超えないようgainDbを抑えた。サブ役は基準値を使用。固定ゲインではないので[全編測定・登録記録](../../houkago-stella-voice/samples/full-v2/installation.json)と各言語manifestを参照。原音に追加加工はしていない。RMS・サンプルピークの測定であり、LUFS・真のピーク・BGMとの合成ピーク・聴感の評価ではない。

## 今後の判断

- 英語テキスト＋日本語ボイスを選べる独立した音声言語設定が必要か。現在は表示言語に連動。
- キャラ別ミュート／音量をプレイヤー設定に出すか。現在はボイス全体のみ。
- 台詞中にBGMを少し下げる機能が必要か。実際の音声をBGMと重ねて判断する。
