## システム・UI

  - [ ] **エピローグの始まり方について**
    - EDロール終わり → (前シーンの)背景やキャラが表示される → 暗転描写 → エピローグ開始、といった感じの流れだがこれを<br>
      EDロール終わり → エピローグ開始、とシームレスな流れにできないか？
    - 章の切り替わりも似たような感じだな･･･、開始 → 背景や立ち絵表示→暗転→・・・みたいな。始まってるのに暗転？みたいな印象になってしまう。
    - デバッグ報告14より引き続き…
      - → EDロールからエピローグ開始部分は修正させれてよくなった。
      - → 章の切り替わり部分について、章タイトル表示 → そのまま次の章が始まる、といった感じになってるが<br>
        章タイトル表示 → 暗転が開ける描写(背景や立ち絵など描写しないで暗転の後半部分だけ使うみたいな) → 次の章開始、<br>
        といった感じにできないか。
    - 対応（1.3.9）：章タイトルの後、黒い画面の下で次章の背景・立ち絵・文章を準備し、暗転の開く部分（600ms）のみを表示するよう修正。次章が先に見えることを防ぎ、実ブラウザーで章移動・キャンセル・EDからエピローグへの移行を確認済み。
    - さらにデバッグ報告15より引き続き…
      - → 希望したとおりの修正になってる。ただ暗転が開く処理をもう少しゆっくりの方がいいと思う。倍の1200msでいいかもしれない。
      - この仕様が結構いい感じなのでEDロールからエピローグ部分はそのままと言ってたがそちらでも同じにしてよさそう。
