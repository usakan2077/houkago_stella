# デバッグ報告15
Ver 1.3.8のチェック

対応状況（2026-10-23追記）：章切り替えは1.3.9、楽曲ダウンロードは1.4で対応済み。以下の対応追記は開発側の確認結果です。


---------

## システム・UI

  - [x] **エピローグの始まり方について**
    - EDロール終わり → (前シーンの)背景やキャラが表示される → 暗転描写 → エピローグ開始、といった感じの流れだがこれを<br>
      EDロール終わり → エピローグ開始、とシームレスな流れにできないか？
    - 章の切り替わりも似たような感じだな･･･、開始 → 背景や立ち絵表示→暗転→・・・みたいな。始まってるのに暗転？みたいな印象になってしまう。
    - デバッグ報告14より引き続き…
      - → EDロールからエピローグ開始部分は修正させれてよくなった。
      - → 章の切り替わり部分について、章タイトル表示 → そのまま次の章が始まる、といった感じになってるが<br>
        章タイトル表示 → 暗転が開ける描写(背景や立ち絵など描写しないで暗転の後半部分だけ使うみたいな) → 次の章開始、<br>
        といった感じにできないか。
    - 対応（1.3.9）：章タイトルの後、黒い画面の下で次章の背景・立ち絵・文章を準備し、暗転の開く部分（600ms）のみを表示するよう修正。次章が先に見えることを防ぎ、実ブラウザーで章移動・キャンセル・EDからエピローグへの移行を確認済み。



---------

## その他
  - [x] **楽曲ダウンロード**
    - OP曲やED曲をDLできるようにしてもいいのでは？
      - LPサイトにリンクを作るか…全ルートクリア特典として専用経路を作るとかもいいかも。
    - 対応（1.4）：タイトルの「SOUND MODE」で、BGM32曲とOP・ED4曲、計36曲をMP3でダウンロード可能。各曲の「↓」と、選択中の曲のダウンロードボタンから保存できる。
    - 解放条件はいずれかの最終エンディング到達（GOOD/BAD）。既存のGOOD END記録、または旧版のエピローグCG解放記録からも利用可能。
    - 開発確認：日英の全36曲の再生・個別リンクを確認。日本語BGMと英語OPは実際に保存し、元MP3とのSHA-256一致を確認済み。

詳しい対応・検証結果：[対応記録](../docs/debug-report15-status.md)、[SOUND MODEの演出とダウンロード](../docs/sound-mode.md)。
